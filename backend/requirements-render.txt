# ─────────────────────────────────────────────────────────────────────
# NOTES FOR RENDER DEPLOYMENT
# ─────────────────────────────────────────────────────────────────────
# 1. MongoDB Atlas Connection:
#    - Set MONGO_URL in Render environment variables
#    - Format: mongodb+srv://username:password@cluster.mongodb.net/?retryWrites=true&w=majority
#    - Create Atlas account at: https://www.mongodb.com/cloud/atlas
#
# 2. JWT Secret:
#    - Generate with: python -c \"import secrets; print(secrets.token_urlsafe(32))\"
#    - Set JWT_SECRET in Render environment variables (mark as secret)
#
# 3. Build Time:
#    - Free tier can take 5-10 minutes for initial deployment
#    - Subsequent rebuilds are faster with pip cache
#
# 4. Port Binding:
#    - Render injects $PORT environment variable (usually 10000)
#    - start command uses: uvicorn main:app --host 0.0.0.0 --port $PORT
#
# 5. Health Check:
#    - Render checks GET /health endpoint every 10 seconds
#    - Endpoint is configured in render.yaml
