# Doctor Dashboard

This folder contains the web dashboard used by doctors.

## What It Is For

- Reviewing patient information
- Supporting consultation workflows
- Connecting to the backend API

## How To Run It

The dashboard uses a standard React setup.

```bash
npm install
npm start
```

Open the app in your browser at `http://localhost:3000`.

## Helpful Notes

- Make sure the backend is running before using the dashboard.
- If the page cannot load data, check the backend URL and network settings.
- For the full project overview, read the root `README.md`.
