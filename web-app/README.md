# Web Dashboards

This folder contains the web interfaces used by doctors and hospital staff.

## What Is Inside

- `doctor-dashboard/` - doctor-facing dashboard for reviewing patient information and supporting consultations
- `hospital-dashboard/` - hospital staff dashboard for administrative work and system management

## How To Use Them

Open the dashboard folder you want to work with, then install dependencies and start the app using that app's normal React commands.

## Notes

- Start the backend first so the dashboards can load data.
- The `build/` and `node_modules/` folders are generated and should not be committed.
- For the main project overview, read the root `README.md`.
