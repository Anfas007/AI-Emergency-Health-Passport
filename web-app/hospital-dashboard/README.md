# Hospital Dashboard

This folder contains the web dashboard used by hospital staff.

## What It Is For

- Managing hospital users and records
- Supporting admin tasks
- Connecting to the backend API

## How To Run It

Use the setup command for this dashboard's React app.

```bash
npm install
npm start
```

Open the app in your browser at `http://localhost:3000`.

## Helpful Notes

- Start the backend first so the dashboard can load data.
- If the dashboard shows errors, check the backend connection and browser console.
- For the full project overview, read the root `README.md`.
