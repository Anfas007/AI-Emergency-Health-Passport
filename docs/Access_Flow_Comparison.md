## Emergency Access Flow
1. Doctor scans patient QR code
2. Emergency token is generated
3. Doctor enters live condition and vitals
4. AI runs automatically and provides predictions
5. Doctor makes final decision
6. Access expires automatically

## Normal Consultation Flow
1. Doctor requests access using Patient ID
2. Patient approves or rejects request
3. Temporary token issued
4. Doctor views selected records
5. Access expires automatically
